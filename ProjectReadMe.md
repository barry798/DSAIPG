# INFO 6205 Project: Tic-Tac-Toe and Connect 4

This project includes implementations of two classic games: **Tic-Tac-Toe** and **Connect 4**, built using Java.

## How to Run

### Tic-Tac-Toe
To run the Tic-Tac-Toe game, execute the following file:
src/main/java/com/phasmidsoftware/dsaipg/projects/mcts/tictactoe/TicTacToe.java

### Connect 4
To run the Connect 4 game, execute the following file:
src/main/java/com/phasmidsoftware/dsaipg/projects/mcts/connect4/Connect4.java
